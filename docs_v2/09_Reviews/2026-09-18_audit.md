## Notable structural changes (Phase 4)

- **Storage layering (#96):** the web layer talks to storage only through
  `StorageProtocol`/`ObjectStorageProtocol`; a layering guard test enforces that `services/`,
  `core/`, `utils/`, `config/` never import `publisher_v2.web`.
- **Configuration collapse (#97, four staged PRs):** phantom/mismatched feature flags fixed and
  centralized; runtime tunables parsed in `config/runtime_settings.py` with an AST guard test on
  ad-hoc `os.environ` reads; dead email/SMTP config wired; the INI path and orchestrator schema
  v1 builder removed (env-only configuration, schema v2 only).
- **Docs realignment (#98):** this summary, plus a doc test asserting every feature flag in
  [CONFIGURATION.md](../05_Configuration/CONFIGURATION.md) is parsed by the config layer — in
  both directions.
